# CNPM-NC

Web bán điện thoại xây dựng bằng ASP.NET Core Razor Pages trên .NET 8.

## Yêu cầu

- .NET 8 SDK

## Chạy ứng dụng

Từ thư mục gốc của repository:

```powershell
dotnet restore Web_BanDT.sln
dotnet build Web_BanDT.sln
dotnet run --project Web_BanDT/Web_BanDT.csproj
```

Mở URL được hiển thị trong terminal để truy cập ứng dụng.
